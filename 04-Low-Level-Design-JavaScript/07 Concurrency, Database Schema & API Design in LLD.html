Concurrency Primitives (Mutex, Deadlocks & Optimistic Locking)

ConcurrencyMutexDeadlocksDB Locking

Race conditions happen when multiple concurrent async workers mutate shared memory state simultaneously. A Mutex guarantees mutual exclusion during state mutation.

Runnable Async Mutex Implementation

JavaScript — Async Mutex Implementation
class AsyncMutex {
    #locked = false;
    #queue = [];

    async acquire() {
        return new Promise(resolve => {
            if (!this.#locked) {
                this.#locked = true;
                resolve();
            } else {
                this.#queue.push(resolve);
            }
        });
    }

    release() {
        if (this.#queue.length > 0) {
            const nextResolve = this.#queue.shift();
            nextResolve();
        } else {
            this.#locked = false;
        }
    }
}

const mutex = new AsyncMutex();
let accountBalance = 100;

async function withdraw(userId, amount) {
    await mutex.acquire();
    try {
        console.log(`[USER ${userId}] Current balance: $${accountBalance}`);
        if (accountBalance >= amount) {
            await new Promise(r => setTimeout(r, 50)); // Simulate async DB delay
            accountBalance -= amount;
            console.log(`[USER ${userId}] Withdraw $${amount} SUCCESS! New balance: $${accountBalance}`);
        } else {
            console.log(`[USER ${userId}] Withdraw FAILED! Insufficient funds.`);
        }
    } finally {
        mutex.release();
    }
}

Promise.all([withdraw("A", 80), withdraw("B", 80)]);

REST API Design & X-Idempotency-Key Middleware

API DesignExpress.jsIdempotency

Idempotent REST APIs ensure that repeating an HTTP request multiple times yields the exact same server state without duplicate charges.

JavaScript / Express.js — Idempotency Middleware
const idempotencyStore = new Map();

function idempotencyMiddleware(req, res, next) {
    const key = req.headers['x-idempotency-key'];
    if (!key) return next();

    if (idempotencyStore.has(key)) {
        const cached = idempotencyStore.get(key);
        console.log(`[DUPLICATE REQUEST PREVENTED] Serving cached response for key: ${key}`);
        return res.status(cached.status).json(cached.body);
    }

    const originalJson = res.json.bind(res);
    res.json = (body) => {
        idempotencyStore.set(key, { status: res.statusCode, body });
        return originalJson(body);
    };
    next();
}

console.log("Idempotency Middleware Ready.");
